# Recipe: Check against a template

## When it fits

The person reviews documents others write (briefs, requests, proposals) against a template or a standard and sends back what is missing.

## What to ask

- Which template or standard is the reference? Add it to the sources list.
- Which sections are required, and which are optional?
- Who gets the reply, and how formal should it be?

## Inputs and checks

- The document to check: `md`, `txt`, or `pdf`, or read through a connected service.
- The template, from the sources list.

## Facts step

Useful when the document is a file: list each required section heading and whether it is present and empty. Leave judgment about quality to the written result.

## The result

- Literal gaps: required sections that are missing or empty, in template order.
- Quality gaps: placeholder text (such as "TBD", "to come", "per finance"), contradictions between sections, and claims without a source.
- A short reply draft to the author, polite and specific, listing what to add. Never send it; say where to paste it.
- End with "Sources:" naming the template and its version.

## Checklist items to include

- Lists every required section that is missing or empty.
- Flags every placeholder such as "TBD" with its section.
- Includes a reply draft to the author.

## Numbers

Usually none. If the document states numbers, check them only against the sources and say where each one came from.

## Watch out for

- A section with a heading but no real content counts as empty.
- Do not rewrite the author's document. Point to what is missing.

## Example requests

- "Check this brief against the template."
- "What is missing from this request before I approve it?"
